# 데이터 확보 가능성 Matrix

이 표는 공식 문서 확인 없이 API 존재를 가정하지 않는다는 원칙(§6)에 따라, **일반적으로 널리 알려져
있고 실제 운영 이력이 있는 공식 공공데이터셋**을 1차 후보로 정리한 것이다. 실제 연동 전 반드시
공공데이터포털(data.go.kr) / 각 기관 개발자센터에서 최신 API 명세, 인증방식, 호출한도를 재확인해야
한다. 현재 코드베이스는 **모든 Provider가 Mock 모드로 동작**하며, `mode: 'live'` 구현은 아직 없다
(README 참고).
